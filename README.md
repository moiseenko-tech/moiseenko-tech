## My AI Principles

> [Vibe coding is not the same as disciplined agentic development.](https://x.com/unclebobmartin/status/2031396174490472638?s=46)
> — Robert C. Martin

*How I work with AI:*

1. **AI is a tool, not a co-author.** I take full responsibility for every line of code, every decision, every outcome — regardless of what AI produced.

2. **Plan before implementation.** No code is written until a `PLAN.md` is ready — a detailed, step-by-step implementation plan clear enough for a junior or mid-level developer to pick up and continue.

3. **Feature work starts with a product owner mindset.** Before involving AI, I work out user scenarios, talk to stakeholders, and define constraints. AI needs to understand not just *what* to build, but *for whom*, *why*, and *within what limits*.

4. **Small, reviewable iterations.** One iteration covers exactly as much as I can review in a single pass — typically 50–200 lines. AI waits for an explicit go-ahead before moving on.

5. **Tests are mandatory and always come first.** No implementation without a test suite written beforehand.

6. **Tests are a contract.** Once agreed upon, tests define the expected behavior and AI is not allowed to modify them during implementation.

7. **AI is isolated from production by design.** AI operates only on the local machine and has no path to deployments — not by policy, but by architecture. Ensuring that isolation is my responsibility.

8. **Engineering practices must be explicit.** Every convention, constraint, and workflow rule — whether personal or team-wide — must be written down in the agent's instruction file. AI should never be expected to infer or guess them. See my [CLAUDE.md](https://github.com/moiseenko-tech/dotfiles/blob/main/claude/CLAUDE.md).
